# Contributions

This folder is for students to submit high-quality code contributions related to the course.

## How to Contribute

1. **Folder Structure:**
   - Create a subfolder using your GitHub username inside `students/contributions/`.
   - Example:  
     ```
     contributions/your_github_username/
     ```

2. **Add Your Code:**
   - Place well-structured and properly commented code in your folder.
   - Include a `README.md` file to explain your work.

3. **Commit and Push:**
   - Create a new branch or switch to an existing branch.
   - Add your changes and commit with a meaningful message.
   - Push your changes to your GitHub fork.

4. **Create a Pull Request (PR):**
   - Open a pull request to the main repository.
   - Add your friend and the instructor as reviewers.
   - Your code will be reviewed and approved before merging.

## Notes

- Ensure your code follows best practices.
- Contributions in this folder should be of high quality.
- Always work on branches for experimental or practice code.

Happy coding!
