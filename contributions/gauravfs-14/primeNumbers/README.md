# PrimeNumbers

This project provides a set of utilities to check various properties of prime numbers. It includes functions to determine if a number is a prime, right-truncated prime, left-truncated prime, Emirp prime, and circular prime.

## Functions

### isPrime

```cpp
bool isPrime(int num);
```

Checks if a number is prime.

### isRTPrime

```cpp
bool isRTPrime(int num);
```

Checks if a number is a right-truncated prime.

### isLTPrime

```cpp
bool isLTPrime(int num);
```

Checks if a number is a left-truncated prime.

### isEmirp

```cpp
bool isEmirp(int num);
```

Checks if a number is an Emirp prime.

### isCircularPrime

```cpp
bool isCircularPrime(int num);
```

Checks if a number is a circular prime.

## Example

```sh
Enter a positive integer: 37
37 is a prime number.
37 is a right-truncated prime.
37 is not a left-truncated prime.
37 is an Emirp prime.
37 is a circular prime.
```
