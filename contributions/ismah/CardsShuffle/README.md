# Vector Shuffling (Deck of Cards)

This program demonstrates how to create, shuffle, and print a deck of cards using vectors, shuffle function (algorithm library), random number generation for shuffling.

## What the Three Functions Do

1. In the "deckCreation" function, the deck is created by combining a vector of card ranks and a vector of suits into a new vector containing the full deck.
2. The "shuffle" function shuffles the deck using "shuffle" from the algorithm library and random_device number generator.
3. "printDeck" prints the shuffled deck through a for loop.
